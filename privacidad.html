Política de privacidad

Panel de redes · Última actualización: 30 de septiembre de 2026

Summary (English): Panel de redes is a personal, local-first desktop dashboard. It reads statistics of the user's own YouTube, Instagram, Facebook Pages and TikTok accounts using read-only permissions. All data and access tokens are stored only on the user's own computer (tokens encrypted with Windows DPAPI). The developer runs no server, receives no data, and does not sell or share it. Users can disconnect an account at any time, which deletes its stored data. Contact: eldatoeco@gmail.com.

1. Quién es el responsable

Eduardo Naranjo, desarrollador de «Panel de redes». Contacto: eldatoeco@gmail.com.

2. Qué es esta aplicación

«Panel de redes» es una aplicación para Windows, de uso personal y privado entre un grupo reducido de personas conocidas, que muestra en un solo panel las estadísticas de las propias cuentas de YouTube, Instagram, Facebook (páginas) y TikTok de cada persona. Funciona en el computador de cada usuario y se abre en su navegador. No es un servicio público ni tiene un servidor del desarrollador.

3. Qué datos se consultan

Solo con permisos de lectura y solo de la cuenta que la persona decide conectar:

RedDatos que se leen
YouTube (Google)Nombre del canal, suscriptores, vistas, videos (título, miniatura, vistas, me gusta, comentarios) y vistas diarias y tiempo de visualización (YouTube Analytics).
InstagramNombre de usuario, seguidores, publicaciones (texto, miniatura, me gusta, comentarios) y sus métricas: vistas, alcance, guardados y compartidos.
Facebook (páginas)Nombre de la página, seguidores, publicaciones (texto, imagen, reacciones, comentarios, compartidos) y vistas. El permiso de portafolio comercial solo se usa para localizar las páginas de la persona.
TikTokNombre visible, número de seguidores y de videos, y por video: título, portada, vistas, me gusta, comentarios y compartidos.

No se leen mensajes privados, contactos, contraseñas ni información de terceros, y la aplicación no publica ni modifica nada en las cuentas.

4. Cómo se obtiene el acceso a tu cuenta

Al iniciar sesión, cada plataforma entrega a la aplicación un código de autorización y luego un token de acceso. Ese token es lo único «sensible» que se guarda; la aplicación nunca ve ni almacena la contraseña de la persona.

5. Dónde se guardan

  • Las cifras, publicaciones y tokens se guardan únicamente en el computador del usuario, en una base de datos local.
  • Los tokens se cifran con la protección de datos de Windows (DPAPI), atados a la cuenta de Windows de esa persona.
  • El desarrollador no recibe, no almacena ni tiene acceso a los datos de otras personas.

6. Página puente de inicio de sesión

Algunas plataformas exigen que el inicio de sesión termine en una dirección HTTPS. Para eso se usa la página https://eduardonv9.github.io/panel-redes-puente/, alojada en GitHub Pages. Esta página solo reenvía el resultado del inicio de sesión al computador del usuario (localhost); no guarda ni procesa datos. Como cualquier sitio web, GitHub puede registrar datos técnicos de acceso según su propia política (GitHub Privacy Statement).

7. Uso y comparticiones

  • Los datos se usan únicamente para mostrarle al propio usuario sus estadísticas.
  • No se venden, no se ceden, no se usan para publicidad ni para entrenar modelos, y no se comparten con terceros.
  • La aplicación solo se comunica con las interfaces oficiales (APIs) de Google/YouTube, Meta (Instagram y Facebook) y TikTok.

El uso de la información recibida de las APIs de Google cumple la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

8. Conservación y eliminación

  • El usuario puede pulsar «Desconectar» en el panel: se borran de su computador los datos y el token de esa cuenta. También puede borrar un perfil completo.
  • Puede revocar el acceso en cualquier momento desde la plataforma: Google, Instagram y Facebook (Configuración → Apps y sitios web) y TikTok (Configuración → Seguridad y permisos → Permisos de la app).
  • Al desinstalar la aplicación y borrar su carpeta de datos, no queda información en ningún otro lugar.

9. Derechos del titular (Ley 1581 de 2012, Colombia)

Como los datos no salen del computador del propio usuario, él mantiene el control total. Aun así, cualquier persona puede escribir a eldatoeco@gmail.com para preguntar sobre esta política o ejercer sus derechos de conocer, actualizar, rectificar y suprimir sus datos.

10. Menores de edad

La aplicación no está dirigida a menores de 18 años.

11. Cambios

Si esta política cambia, se actualizará esta página y su fecha.
